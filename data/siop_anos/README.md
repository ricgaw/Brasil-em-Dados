# Anos aprovados do SIOP

Após revisão e merge da PR anual, ficam aqui `<ano>.csv` e `<ano>.json`.

- CSV: funções de um único ano, proveniente de arquivo oficial verificado.
- JSON: auditoria incluindo o SHA-256 do arquivo original e eventual Reserva de Contingência.
- Arquivos de anos aprovados não são sobrescritos pelo workflow; revisões requerem procedimento editorial próprio.
- A consolidação de anos aprovados só altera o site depois de uma segunda Pull Request revisada.

**Não insira valores fictícios ou agregue dados de fontes diferentes neste diretório.**
